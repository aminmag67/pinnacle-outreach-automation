INSTALLATION COMMANDS
================================================================================

1. Install Python packages (run once):
   pip install anthropic google-auth-oauthlib google-auth-httplib2 google-api-python-client gspread python-dotenv

2. Set API key (PowerShell - session only):
   $env:ANTHROPIC_API_KEY="sk-ant-YOUR_KEY"

3. Set API key permanently (PowerShell - persists):
   [Environment]::SetEnvironmentVariable("ANTHROPIC_API_KEY","sk-ant-YOUR_KEY","User")

RUNNING THE AGENT
================================================================================

SAFETY MODES (IMPORTANT)
================================================================================

SAFE_MODE defaults to true.
When SAFE_MODE=true, Gmail draft creation is skipped.

--dry-run is a draft-action dry run:
  - Skips Gmail draft creation only
  - May still call Anthropic for generation

credentials.json is required only when SAFE_MODE=false and DRY_RUN=false.

Safe default run:
  python pinnacle_outreach_agent_utf8_fixed.py

Draft-action dry run:
  python pinnacle_outreach_agent_utf8_fixed.py --dry-run

Enable Gmail draft creation only after explicit approval:
  python pinnacle_outreach_agent_utf8_fixed.py --safe-mode false

WARNING: Do not use --safe-mode false until credentials are configured and
you are ready for Gmail drafts to be created.

Manual run (for testing):
   python pinnacle_outreach_agent_utf8_fixed.py

Background run (recommended):
   Start-Process python -ArgumentList "pinnacle_outreach_agent_utf8_fixed.py" -NoNewWindow

Scheduled run (Task Scheduler - see PINNACLE_README.md for full setup)

TROUBLESHOOTING QUICK FIXES
================================================================================

Issue: "ANTHROPIC_API_KEY is not set"
Fix:   $env:ANTHROPIC_API_KEY="sk-ant-YOUR_KEY"

Issue: "credentials.json not found"
Fix:   Download from Google Cloud Console (see PINNACLE_README.md)

Issue: "Gmail OAuth failed"
Fix:   Delete token.json and restart

Issue: Garbled text (像った・gh？) in Gmail
Fix:   Already fixed! This version uses UTF-8 encoding

Issue: Agent stops unexpectedly
Fix:   Check outreach_log.jsonl for error details

Issue: Gmail drafts not appearing
Fix:   1. Verify Gmail account is amin@pinnaclecontentstudio.com
      2. Check Drafts folder (not Inbox)
      3. Refresh Gmail page

GOOGLE CLOUD SETUP (One-time)
================================================================================

1. Go to: https://console.cloud.google.com
2. Create new project: "Pinnacle Outreach"
3. Enable: Gmail API
4. Create OAuth 2.0 Client ID (type: Desktop app)
5. Download as JSON
6. Save as: credentials.json (in your pinnacle-outreach folder)

First run will open browser for OAuth authorization.
